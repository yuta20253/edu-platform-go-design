## 1. 作成されていない機能

### 1-1. 管理者向け分析機能(`Admin::AnalyticsController`)が①②③のいずれにも存在しない【要対応】

`rails/app/controllers/api/v1/admin/analytics_controller.rb`(`GET /api/v1/admin/analytics`、ルーティングは`resource :analytics, only: :show`)が、KPI・日次アクティビティ・低正答率の単元/問題・高校別利用状況・コンテンツ網羅率を返す独立した機能として実在する。

```ruby
render json: {
  kpis: query.kpis,
  daily_activity: query.daily_activity,
  low_accuracy_units: query.low_accuracy_units,
  low_accuracy_questions: query.low_accuracy_questions,
  high_school_usage: query.high_school_usage,
  content_coverage: query.content_coverage,
  meta: query.meta
}
```

既存の「分析機能」①②③は生徒向け(`Api::V1::Student::AnalyticsController`)専用であり、この管理者向けエンドポイントへの言及はない(①②③とも`grep`で無検出)。「管理者ダッシュボード機能」にも記載がない。`計画書/tmp/残タスク.md`の「全33機能」一覧にも対応する項目がなく、34機能(新設のユーザー基盤・カレンダーを含む)のどの文書にも割り当てられていない。

**①②③を新規作成する機能が1件漏れている。** カレンダー機能(2026-11-10に新設)と同じ進め方(`/spec:rails` → `/spec:design` → `/spec:impl`)が必要。

### 1-2. 面談機能の「担当教員一覧取得」APIが①②③に文書化されていない【要対応】

`rails/app/controllers/api/v1/student/teachers_controller.rb`(`GET /api/v1/student/teachers`)は次のように実装されている。

```ruby
# 面談申請先として選べる、自分の学級の担当教員(論理削除済みを除く)
def teachers
  school_class = current_user.school_class
  return User.none if school_class.nil?
  school_class.teachers.active.order(:id)
end
```

面談機能①は「生徒は自分が所属するクラスの担当教員を指定して面談を申請できる」という業務ルールは記載しているが、その担当教員一覧を取得するこのエンドポイント自体(Controller・Route・Request/Response)はAPI一覧表のどこにも記載がなく、②③にも登場しない(`grep`で無検出)。面談申請フォームの教員選択に使う実在のAPIが1件、仕様書化から漏れている。

### 1-3. 他のRailsルーティングとの突き合わせ結果

`rails/config/routes.rb`の全エントリを①②③およびRails実装側コメントと照合し、上記2件以外はすべて既存34機能のいずれかに割り当てられていることを確認した(例: `admin/csv_template/questions`→管理者問題インポート機能、`admin/high_schools`配下の`teachers`/`grades`/`announcements`→それぞれ管理者教員管理・管理者高校学年参照・管理者お知らせ管理、`teacher/grades`→クラス編成機能、等)。`タスク下書き`・`管理者コース・単元参照`のルーティング上存在するが未実装のアクションは`計画書/tmp/未確定・保留事項.md`6章に既記載。

## 3. 設計書間の不整合

### 3-1. ①②③間のファイル名対応

機械的に diff した結果、①②③間に孤立ファイルは**ユーザー基盤機能(②③のみ、①なし)の1件のみ**であり、これは個別Railsコントローラに対応しない新設Contextとして意図的な例外である(カレンダー機能は①②③すべて揃っている)。それ以外の33機能は①②③が1:1で対応している。

### 3-2. 他Context側へ未反映の公開操作(呼び出し側③が前提にしているが、所有Context側②に定義がない)

本日時点で3件が未解消のまま残っている(いずれも`計画書/tmp/残タスク.md`バッチ11・12で記録され、実体を確認済み)。

| 必要な操作 | 所有Context | 必要としている機能 |
|-|-|-|
| `profile`からの参照操作(`FindProfileSummary`相当) | `profile`(プロフィール管理機能) | 認証機能③ |
| 学級名からの学級解決操作 | `school-class`(クラス編成機能) | 生徒CSVインポート機能③(`GradeClassResolutionRepository`) |
