# チケット: 学年平均の母集団修正

**対象ロール**: 生徒　**元の番号**: A11

参照元: [Rails修正のフロント影響.md](./Rails修正のフロント影響.md)

## 現状

学年平均の母集団（`grade_average.rb#grade_users`）が`User.joins(:grade).where(grades: { year: ... })`のみで絞っており、ロール・在籍のいずれも絞っていない。`users.grade_id`は教員も持つため、教員の解答履歴・タスクが生徒の学年平均に混入している。順位算出（`rank.rb`）は`merge(User.active)`で論理削除済みを除外しているが、学年平均側は除外していない不統一もある。

## 修正方針

`grade_users`を次のように変更する。

```ruby
User.students.active.joins(:grade).where(grades: { year: @user.grade.year })
```

## フロント影響

なし。レスポンスの構造は変わらず、数値のみ変わる。

## 該当箇所

`app/services/student/analytics/grade_average.rb#grade_users`

## 備考

教員が母集団から抜けることで学年平均の数値が実際に変わるため、着手前に業務側の確認が必要。他校の同一年次が混ざることはA10により仕様として許容されており、本修正後の母集団は「全校の同じ年次の在籍生徒」になる。
