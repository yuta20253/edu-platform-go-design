# 教師ダッシュボード機能 Rails現行仕様書

---

# 1. 機能概要

- 機能の目的
  - 教師のホーム画面に同校の生徒数と教師向けのお知らせを表示すること。
- システム上の役割
  - 同校の学年別生徒数を集計する。
  - 教師に表示可能な公開中のお知らせを取得する。
- 利用者
  - `teacher` ロールのユーザー（教師）

---

# 2. 機能一覧

|操作|概要|
|-|-|
|表示|同校の学年別生徒数と教師向けお知らせを取得する|

---

# 3. 業務フロー

1. 教師がダッシュボードを表示する。
2. システムは同校の生徒数を学年別に集計する。
3. 公開中の教師向けお知らせを最新順で取得する。
4. ダッシュボード情報を返却する。

# 5. API / 処理詳細

## `Api::V1::Teacher::DashboardsController#show`

### 概要

同校の生徒数を学年別に集計し、教師向けのお知らせを最新 5 件取得する。

### Request

- なし

### 処理内容

1. 操作者が所属する高校の生徒のうち、学年の年次が1〜3のものを対象とし、年次ごとに人数を数える。
2. 操作者を配信対象に含む公開中のお知らせを、配信日時の新しい順に最大5件取得する。
3. 年次ごとの人数とお知らせを返却する。

### 業務ルール

- 生徒数は同校の生徒のみを対象とする。
- 生徒数の集計対象は、学年（`grades.year`）が1〜3のもののみである。
- 生徒数には、無効化済み（`deleted_at`あり）の生徒も含まれる（`active`による除外は行わない）。
- お知らせは、操作者を配信対象に含み、かつ公開中のもののみ返却する。下書き・配信予定のものは含まれない。
- お知らせの並び順は配信日時の降順である。

### Database変更

- なし

### Response

- **200 OK**
- `stats`
  - `grade_one_students_count`（年次1の生徒数）
  - `grade_two_students_count`（年次2の生徒数）
  - `grade_three_students_count`（年次3の生徒数）
- `announcements`（最大5件。各要素は `id`, `title`, `content`, `published_at`, `publisher`）
  - `publisher` は `id`, `name`, `name_kana` の3項目

**年次ごとの人数は3項目で固定である。** 年次が4以上の学年や、学年が設定されていない生徒は集計に現れない。該当する生徒がいない年次は0を返す。

お知らせの項目は一覧画面より少ない。**状態・配信予定日時・作成日時・配信対象は含まれない。** ダッシュボードでは公開中のものだけを表示するため、状態や配信対象の判断材料を必要としないためである。

### Errorケース

- なし（認証前提）

# 6. データモデル

## `announcements`

- 役割: お知らせを管理するテーブル
- 主なカラム: `id`, `title`, `content`, `status`, `published_at`, `scheduled_at`, `publisher_id`
- リレーション: `has_many :announcement_targets`

---

# 7. 状態管理

本機能は状態を持たず、状態を変更しない。

返すお知らせの状態（下書き・配信予定・公開中）は、管理者お知らせ管理機能・教師お知らせ機能が管理するものである。本機能は公開中のものだけを絞り込んで表示し、状態そのものはレスポンスに含めない（「5. API / 処理詳細」`#show`）。

---

# 8. 権限制御

- `current_user` が `teacher` ロールであることが前提。
- 公開中かつ教師が閲覧可能な `Announcement.for_user` の絞り込みが適用される。

---

# 9. 非同期処理

なし。本機能は参照のみであり、ジョブ・メール送信を伴わない。
