# 管理者高校学年参照機能 Rails現行仕様書

---

# 1. 機能概要

- 機能の目的
  - 管理者が、システムに登録されている高校の一覧と詳細、および高校ごとの在籍人数を把握できるようにすること。あわせて高校に属する学年を参照できるようにすること。
- システム上の役割
  - 参照専用の機能である。高校・学年の登録・更新・削除を行う操作はこの機能に含まれない。
  - 高校そのものの情報に加えて、**その高校に所属する生徒数・教員数を集計して返す。** 共通マスタ参照機能が入力フォームの選択肢として高校を返すのに対し、本機能は運用状況の把握を目的とする。
  - 高校の詳細から、その高校の教員管理・お知らせ参照といった管理画面へ遷移する起点にもなる。
- 利用者
  - `admin` ロールのユーザー（管理者）のみ。

---

# 2. 機能一覧

|操作|概要|
|-|-|
|高校一覧取得|高校を都道府県で絞り込み、ページ単位で取得する。生徒数・教員数を含む|
|高校詳細取得|指定した高校の情報と、生徒数・教員数を取得する|
|学年一覧取得|指定した高校に属する学年を年次の昇順で取得する|

---

# 3. 業務フロー

1. 管理者が高校の一覧を要求する。必要に応じて都道府県で絞り込み、ページを指定する。
2. システムは該当する高校をページ単位で取得し、それぞれの在籍生徒数・在籍教員数を集計して返す。
3. 管理者が一覧から高校を選び、詳細を要求する。
4. システムは指定された高校を取得する。存在しない場合はエラーとして返す。
5. システムは高校の情報と生徒数・教員数を返す。
6. 管理者が必要に応じて、その高校の学年一覧を要求する。
7. システムは指定された高校を取得し、属する学年を年次の昇順で返す。

---

# 4. API一覧

|Controller|Action|HTTP Method|Endpoint|概要|
|-|-|-|-|-|
|`Api::V1::Admin::HighSchoolsController`|`index`|GET|`/api/v1/admin/high_schools`|高校一覧を取得|
|`Api::V1::Admin::HighSchoolsController`|`show`|GET|`/api/v1/admin/high_schools/:id`|高校詳細を取得|
|`Api::V1::Admin::GradesController`|`index`|GET|`/api/v1/admin/high_schools/:high_school_id/grades`|指定高校の学年一覧を取得|

# 5. API / 処理詳細

## `Api::V1::Admin::HighSchoolsController#index`

### 概要

高校を都道府県で絞り込み、ページ単位で取得する。各高校の在籍生徒数・在籍教員数を含む。

### Request

|項目|必須|型|説明|
|-|-|-|-|
|`prefecture_id`|任意|integer|都道府県の識別子。未指定・空文字のときは絞り込まない|
|`page`|任意|integer|ページ番号。0以下・数値以外は未指定として扱う|
|`per_page`|任意|integer|1ページあたりの件数。既定20、上限100。0以下・数値以外は既定値|

### 処理内容

1. 高校を都道府県で絞り込む。未指定のときは絞り込まない。
2. 識別子の昇順に並べ、指定されたページを取得する。
3. 取得したページに含まれる高校について、在籍生徒数を高校ごとに集計する。
4. 同じ高校について、在籍教員数を高校ごとに集計する。
5. 高校の情報に生徒数・教員数を添えて、ページ情報とあわせて返す。

### 業務ルール

- `admin` ロールのユーザーのみ利用できる。
- 都道府県の絞り込みは、未指定・空文字のときは適用しない。全件が対象になる。共通マスタ参照機能の高校検索とは扱いが異なる。
- 並び順は識別子の昇順。高校名の昇順ではない。
- ページネーションの既定値と上限は、全APIで共通の値（既定20、上限100）に従う。
- 集計は取得したページに含まれる高校に限る。ページ外の高校は集計しない。
- **生徒数は在籍中の生徒のみを数える。** 論理削除済み（統合済み）の生徒は含まない。
- **教員数は論理削除済みの教員も含む。** 生徒数と扱いが一致していない。
- 生徒・教員が0人の高校も一覧に現れ、件数は `0` となる。
- 該当する高校がない場合は空の配列とページ情報を返す。エラーにしない。

### Database変更

- なし

### Response

HTTP Status は `200`。

|項目|型|説明|
|-|-|-|
|`schools`|array|高校の配列|
|`schools[].id`|integer|高校の識別子|
|`schools[].name`|string|高校名|
|`schools[].prefecture_name`|string|所属する都道府県名|
|`schools[].student_count`|integer|在籍中の生徒数|
|`schools[].teacher_count`|integer|教員数（論理削除済みを含む）|
|`meta.current_page`|integer|現在のページ番号|
|`meta.total_pages`|integer|総ページ数|
|`meta.total_count`|integer|総件数|
|`meta.per_page`|integer|1ページあたりの件数|

都道府県の識別子・学校コード・`csv_managed` は返さない。都道府県は名称のみを返す。

### Errorケース

|条件|HTTP Status|内容|
|-|-|-|
|該当なし|200|空の配列とページ情報を返す。エラーにしない|
|未認証|401|認証されていない|
|`admin` ロール以外|403|`{"errors": ["この操作を行う権限がありません"]}`|

## `Api::V1::Admin::HighSchoolsController#show`

### 概要

指定した高校の情報と、在籍生徒数・在籍教員数を返す。

### Request

|項目|必須|型|説明|
|-|-|-|-|
|`id`|必須|integer|高校の識別子。パスに含まれる|

### 処理内容

1. 指定された高校を取得する。存在しない場合はエラーを返す。
2. その高校の在籍生徒数を数える。
3. その高校の在籍教員数を数える。
4. 高校の情報に生徒数・教員数を添えて返す。

### 業務ルール

- `admin` ロールのユーザーのみ利用できる。
- **高校の実在確認を行う。** 存在しない識別子を指定した場合は `404` を返す。共通マスタ参照機能の学年一覧取得とは扱いが異なる。
- 生徒数・教員数の数え方は一覧取得と同じ。生徒は在籍中のみ、教員は論理削除済みを含む。
- 返す項目は一覧の各要素と同じであるが、**配列ではなく単体のオブジェクトを最上位に返す。** `schools` のようなキーでは包まない。

### Database変更

- なし

### Response

HTTP Status は `200`。最上位はJSONオブジェクト。

|項目|型|説明|
|-|-|-|
|`id`|integer|高校の識別子|
|`name`|string|高校名|
|`prefecture_name`|string|所属する都道府県名|
|`student_count`|integer|在籍中の生徒数|
|`teacher_count`|integer|教員数（論理削除済みを含む）|

### Errorケース

|条件|HTTP Status|内容|
|-|-|-|
|存在しない高校の識別子|404|`{"message": "High schoolが見つかりません"}`|
|未認証|401|認証されていない|
|`admin` ロール以外|403|`{"errors": ["この操作を行う権限がありません"]}`|

`404` の本文に入るモデル名が英語表記（`High school`）になるのは、日本語訳が定義されていないためである。

## `Api::V1::Admin::GradesController#index`

### 概要

指定した高校に属する学年を、年次の昇順で返す。

### Request

|項目|必須|型|説明|
|-|-|-|-|
|`high_school_id`|必須|integer|高校の識別子。パスに含まれる|

### 処理内容

1. 指定された高校を取得する。存在しない場合はエラーを返す。
2. その高校に属する学年を年次の昇順で取得する。
3. 識別子・年次・表示名を返す。

### 業務ルール

- `admin` ロールのユーザーのみ利用できる。
- **高校の実在確認を行う。** 存在しない識別子を指定した場合は `404` を返す。共通マスタ参照機能の学年一覧取得とは扱いが異なる。
- 並び順は年次の昇順。共通マスタ参照機能の学年一覧取得は並び順を指定していない。
- ページネーションを行わない。全件を返す。
- 表示名は年次から導出する。対応は共通マスタ参照機能①「5. API / 処理詳細」`Api::V1::GradesController#index` と同じ。
- 学年が0件の高校では空の配列を返す。エラーにしない。

### Database変更

- なし

### Response

HTTP Status は `200`。

|項目|型|説明|
|-|-|-|
|`grades`|array|学年の配列|
|`grades[].id`|integer|学年の識別子|
|`grades[].year`|integer|年次|
|`grades[].display_name`|string|年次に対応する表示名|

`meta` は返さない。ページネーションを行わないためである。

所属高校の識別子は返さない。

### Errorケース

|条件|HTTP Status|内容|
|-|-|-|
|存在しない高校の識別子|404|`{"message": "High schoolが見つかりません"}`|
|未認証|401|認証されていない|
|`admin` ロール以外|403|`{"errors": ["この操作を行う権限がありません"]}`|

# 6. データモデル

本機能が参照するテーブルは、共通マスタ参照機能①「6. データモデル」が整理している `high_schools`・`grades` と同じである。加えて人数の集計で `users` を参照する。

|テーブル|役割|集計・参照で使う主なカラム|
|-|-|-|
|`high_schools`|在籍高校マスタ|`id`, `name`, `prefecture_id`|
|`prefectures`|都道府県マスタ|`id`, `name`|
|`grades`|学年マスタ|`id`, `high_school_id`, `year`|
|`users`|ユーザー|`id`, `high_school_id`, `user_role_id`, `deleted_at`|
|`user_roles`|ロール|`id`, `name`|

リレーション:

- `high_schools` は1つの `prefectures` に属する。都道府県名は結合して取得する。
- `high_schools` は複数の `grades` を持つ。
- `users.high_school_id` によって高校に所属する。ロールは `user_roles` との結合で判定する。

人数の集計で使う絞り込み:

|集計|絞り込み|
|-|-|
|生徒数|ロールが `student`、かつ論理削除されていない、かつ対象の高校に所属する|
|教員数|ロールが `teacher`、かつ対象の高校に所属する（論理削除を問わない）|

`high_schools`・`grades` は論理削除の列を持たない。`users` のみ `deleted_at` を持ち、生徒数の集計でのみ除外される。

---

# 7. 状態管理

- なし。本機能が参照する高校・学年は状態を表すカラムを持たない。
- 集計で参照するユーザーの在籍状態（論理削除されているかどうか）は、生徒数の集計条件として使うのみで、本機能が変更することはない。

---

# 8. 権限制御

- 利用可能ユーザー: `admin` ロールのユーザーのみ。3つの操作すべてに適用される。
- 未認証のアクセスは `401`。`admin` 以外のロールは `403`。
- 閲覧制限はない。管理者は全高校の情報と人数を参照できる。所属校による絞り込みは行わない。
- 人数の集計では他のユーザーのデータを参照するが、返すのは人数のみで、個々のユーザーを特定できる情報は返さない。

---

# 9. 非同期処理

- なし。集計はすべてリクエスト時に同期で実行される。
- 集計結果のキャッシュ・事前集計テーブルも使用していない。
